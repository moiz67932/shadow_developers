# Generated test evidence

`phase1-backend.json` is generated by:

```sh
sh scripts/test-integration.sh --json --outputFile=../tests/reports/phase1-backend.json
```

This runs against `nascon_test`, never the competition database. Phase 1 browser
verification uses the Grid infrastructure test; guest-player and Appium reports
belong to their implementation phases. Do not interpret missing reports as passes.
